**X2D** is a subpart of a major initiative and has been selected by Shubham Jain and me as our major project for the **Diploma in Advanced Computing** program. This project showcases the integration of modern web technologies to build robust, scalable web applications.

## Prerequisites

Before you start, make sure you have the following installed on your machine:
